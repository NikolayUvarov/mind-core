# MIND Core

The Mind itself: the intelligence module of MIND Core. It is to run on [MIND Core OS](https://github.com/NikolayUvarov/mind-core-os), the capability-based microkernel operating system written in Rust that is its substrate.

**Status:** starting (2026-10-11). Nothing is implemented here yet. The plan and the first tasks come next.

## The repositories

| Repository | What it holds |
|---|---|
| [mind-core](https://github.com/NikolayUvarov/mind-core) | the Mind, the intelligence module (this repository) |
| [mind-core-os](https://github.com/NikolayUvarov/mind-core-os) | the operating system: a copy of its development repository's `main`, kept up to date |
| [gcu_undocumented_func](https://github.com/NikolayUvarov/gcu_undocumented_func) | where the operating system is developed: its tracks, tasks and agents |

The project's founding documents are in the operating system's repository: the [Constitution](https://github.com/NikolayUvarov/mind-core-os/blob/main/constitution/EN/MIND_CORE_Constitution_v1.6.md) and [RFC 001 Marain](https://github.com/NikolayUvarov/mind-core-os/blob/main/constitution/EN/RFC_001_Marain_v0.4.md), with their Russian texts beside them.

# MIND Core (по-русски)

Сам Разум — модуль интеллекта MIND Core. Он будет работать на [MIND Core OS](https://github.com/NikolayUvarov/mind-core-os), микроядерной операционной системе на Rust с моделью capabilities, которая служит ему основой.

**Состояние:** начало работы (2026-10-11). Здесь пока ничего не реализовано; следующими появятся план и первые задачи.

**Репозитории:**

- **mind-core** — Разум, модуль интеллекта (этот репозиторий).
- **mind-core-os** — операционная система: копия `main` её рабочего репозитория, которая обновляется автоматически.
- **gcu_undocumented_func** — где разрабатывается операционная система: треки, задачи, агенты.

Основополагающие документы проекта лежат в репозитории операционной системы: [Конституция](https://github.com/NikolayUvarov/mind-core-os/tree/main/constitution/RU) и RFC 001 Marain.

**Лицензия:** пока не выбрана. Операционная система распространяется под MIT OR Apache-2.0.
